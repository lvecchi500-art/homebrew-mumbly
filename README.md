# homebrew-mumbly

the homebrew tap for [mumbly](https://heymumbly.com): talk, and it types what you meant. free, and it runs on your mac.

```
brew install --cask lvecchi500-art/mumbly/mumbly
```

needs a mac with apple silicon and macos 26 or later. mumbly updates itself after that, so `brew upgrade` is optional.

remove it with `brew uninstall --cask mumbly`. add `--zap` to delete your data too.

the cask is updated by mumbly's release script on every release. problems or questions: support@heymumbly.com
